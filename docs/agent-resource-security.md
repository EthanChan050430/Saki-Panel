# Agent 账号边界与外部资源读取（2026-10-11）

Agent 以当前登录用户的身份执行。账号功能权限、目标实例授权、实例分配权限、会话沙箱限制和操作审批必须同时满足。关闭沙箱、“完全访问”、模型生成的用户确认文本均不能授予账号权限。

## 角色与无实例用户

- `super_admin` 明确具有全部实例管辖权，包括普通用户创建的实例和没有创建者的历史实例。
- `admin` / `administrator` 的面板管理范围保持原规则；通过 Agent 访问项目时，与普通用户一样必须是创建者或明确被分配的用户。不获得任意宿主机文件或命令执行权限。
- `operator`、自定义角色，以及拥有 `instance.update`、`node.update`、`role.update` 等功能权限的账号，不再被推断为管理员。
- 未关联实例的入口统一显示“无项目”，不代表默认集群文件系统。所有非超级管理员只能访问自己创建或明确分配的实例，操作能力还受全局功能权限与实例分配权限的交集限制。没有实例授权时，实例列表为空；没有选中授权实例时，实例文件、终端、日志、审计和任务工具拒绝执行；实例发现仅返回已授权项目的 ID、名称和状态。
- 非超级管理员即使关闭沙箱或启用完全访问，也不能用工具参数切换项目。必须由用户在界面选择项目；跨项目文件读取仍走单次外部审批。服务端在上下文、日志、项目记忆、OCR 和模型调用前验证当前账号与项目权限；工具执行、审批恢复、任务回放与回滚继续复验。
- 文件读取、写入和删除分别授权。读取已有内容的编辑、上传覆盖、压缩与解压要求读取及写入权限；补丁删除还要求删除权限。只有写入权限时可新建文件，新建成功后才记录空内容回滚检查点；不会先读取现有文件。只有删除权限时不生成包含原文的删除预览。模型的工具清单根据服务端权限过滤，系统上下文明确显示“无项目”和有效权限。
- 工具入口、命中缓存之前、审批恢复和回滚都重新检查当前权限及账号状态。撤销实例分配后，旧审批和缓存不能继续授予访问。已经交给模型或用户的历史内容不能收回。
- 概述页与浮动聊天的本地会话缓存按账号隔离，无账号归属的旧缓存不自动导入。Agent 任务详情、回放与继续指令验证当前实例授权，任务流失权后停止发送。审批、在途工具和任务恢复记录绑定工作目录及节点连接指纹，目标变化后要求新请求；缺少绑定的旧审批和旧恢复记录不能直接继续。
- 实例和任务列表不复用工具缓存。审计检索与搜索回退都保留实例范围；所有非超级管理员只检索当前选中项目的实例日志，关闭沙箱也不扩大范围。超级管理员开启当前工作区沙箱时同样限于当前项目。无可靠实例归属的历史审计载荷不交给范围受限的 Agent，全局检索仅对超级管理员开放。
- 新检查点绑定创建用户；没有用户归属的历史检查点只允许全局管理员回滚。任务变更、实例设置与文件回滚均检查当前操作权限。

## 单次外部文件读取

新增 `requestExternalAccess({ sourceInstanceId?, path, reason, startLine?, lineCount? })`：

- 普通用户及普通管理员必须提供另一个已授权实例的准确 ID 和工作区相对路径。来源实例必须同时允许 `saki.agent` 和 `file.read`。
- 只有 `super_admin` 可以省略来源实例，申请当前实例所在节点上的绝对宿主机文件路径。所有请求都需要一个有效的当前授权实例。
- 每次读取都需要用户通过审批接口明确批准，包括完全访问和仅规划模式。审批卡直接展示节点、真实文件路径、读取行范围、用途及内容将交给配置模型处理的说明；不接受全局 Y 快捷键误批准。
- 只读取单个本地 UTF-8 普通文件，最大 1 MiB，每次最多 2000 行；不开放外部目录搜索、写入、删除、执行、UNC 或设备文件。
- 后端保存审批目标与文件身份，不相信模型提供的批准状态。审批绑定用户、当前实例、来源实例、节点及其连接地址与配对凭据指纹、工作目录、原始请求、文件身份和版本，15 分钟内有效，执行一次后失效。
- 守护进程验证真实路径及来源工作区范围。批准后检查文件身份与修改时间，从验证后的只读文件描述符读取有上限的数据；文件被替换或改变时要求重新申请。Windows 使用文件句柄的卷标识处理路径 stat 的 dev=0 差异。
- 外部读取不改变当前实例，不扩大终端权限。审批拒绝后继续独立工作。完成一次读取后，本任务的搜索、浏览、爬取、研究及图像服务请求另行展示具体请求并申请一次外发批准；恢复任务时保留这个要求。

第一版使用单次读取，没有会话永久授权或宿主机路径白名单。支持此功能需要面板与守护进程一起更新；旧节点缺少接口时失败并保持原有隔离。

## 宿主机执行与计划任务

当前守护进程没有操作系统级进程沙箱。命令文本检测不能限制项目脚本、依赖、子进程或继承凭据，因此 Agent 的宿主机命令、交互输入、诊断、Git 进程、实例生命周期及执行配置变更暂时仅允许 `super_admin`。普通用户仍可使用已授权实例的专用文件工具。权限模式和手动批准不能绕过这个限制。

未绑定实例的计划任务只对创建者或全局管理员可见，不视为公共任务。HTTP 与 Agent 共用任务授权检查。计划任务定义及修改仅允许全局管理员，避免普通编辑者把恶意命令放进管理员创建的任务后借用其身份执行。自动执行使用任务创建者的当前权限，手动执行使用操作者当前权限，并检查实际启动、停止、重启或终端操作权限；没有有效执行者或创建者失去权限时执行失败。

## 仍需运行环境解决的边界

本次实现是应用层账号授权、受控文件读取和 Agent 执行限制，没有安装或实现容器、操作系统沙箱或网络代理。它没有改造面板原有的独立终端、常驻实例进程及启动机制；写入的项目代码如果被常驻进程自动加载，仍由该进程的操作系统身份执行。因此不能据此宣称共享宿主机上的不可信实例已经实现完整租户隔离。

完整部署隔离仍需要为实例进程及其子进程配置操作系统文件和网络边界，隔离服务凭据、宿主机控制接口及共享目录。出站工具的单次审批也不是端到端信息流跟踪：跨新会话的复制内容和管理员宿主机脚本不受这一外发标记限制。
