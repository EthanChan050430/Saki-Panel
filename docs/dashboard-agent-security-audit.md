## 权限结论

概述页的模式选择和用户手动批准均不能扩大账号权限。没有实例授权的普通用户仍不能读取、修改其他实例；读取已授权外部实例文件也必须经过单次审批。全局实例和宿主机权限仅授予 `super_admin`，普通管理员的权限范围保持受限。

## 概述页权限选项补齐（2026-10-13）

- 概述页补齐独立的“完全访问权限”选项，对应 `bypassPermissions`；默认仍为“自主执行”（`acceptEdits`）。需确认、完全访问和只读观察分别使用 `ask`、`bypassPermissions`、`plan`，直接提交统一的后端权限类型。
- 菜单、按钮图标与选中状态、两处输入框提示使用同一组选项定义；完全访问使用独立颜色，补齐英文翻译。Saki 菜单、内置使用说明与权限文档明确外部文件仍需单次审批。
- 完全访问只改变操作审批方式，账号授权、项目范围、只读限制和后端硬性检查继续生效。
- 本次全项目类型检查、完整构建及现有 6 项概述页回归测试通过；浏览器模拟验证 1280×900 浅色与 390×844 深色下四种模式的选中状态、实际提交参数、首页和会话输入框提示、Chat/Agent 切换与菜单边界。未调用真实模型或执行实例命令，临时验证页面与脚本已移除。

## “无项目”与非超级管理员边界补强（2026-10-12）

- 项目选择、侧栏、输入框和无项目会话标签统一显示“无项目”。项目入口仅显示当前模式下可用、由本人创建或明确分配的项目；分配权限展示读取、写入、删除、日志与任务范围，未授权模式不能切换。
- 修复普通管理员在没有选择项目时可用工具参数直接指定实例的问题。所有非超级管理员必须先选项目，关闭沙箱仍不能通过实例 ID、名称、别名或任务参数改变项目范围。面板原有管理员管理可见性不自动变成 Agent 授权。
- 审计和任务列表即使关闭沙箱也只返回当前项目；无项目审计不查询实例日志。上下文准备在 OCR、日志、项目记忆和模型调用前检查当前账号、项目授权及请求凭据权限，撤权与禁用账号直接拒绝。
- 复合文件工具检查全部所需权限；补丁删除验证 `file.delete`。仅写入权限可以新建文件，新建失败不生成可能删除竞争写入文件的回滚记录；仅删除权限不会读取原文生成预览。
- 模型收到服务端生成的项目范围和有效权限。工具清单先过滤无权限工具，再应用模型数量上限；非超级管理员的执行路径字段和无权写入的图片输出路径不提供给模型。后端仍逐次校验，隐藏工具不替代授权。
- 302 项回归测试、全项目类型检查、完整构建和桌面/移动端浏览器检查通过。覆盖无项目普通管理员、全部审批模式、沙箱开关、明确分配、权限撤销、审计与任务范围、只写新建竞争、补丁删除和超级管理员工具能力。模拟 API/守护进程验证，没有调用真实模型或实例命令。

## 消息与终端交互修复（2026-10-12）

- 用户消息靠右、AI 回复靠左；工具列表以绿色完成、黄色待确认、红色失败、紫色回滚的呼吸点显示状态，保留无障碍标签及减少动态效果设置。默认权限为“自主执行”，对应 `acceptEdits`，风险操作审批和资源授权继续生效。
- 工具详情与列表统一选取同一调用 ID 的最新状态；已完成调用不会再使用历史待审批记录，也不会因查看详情再次发送审批请求。
- 终端调用记录服务端实际使用的实例及独立终端 ID，点击后在右侧显示本次输出与交互终端；支持切换终端和新建终端。创建入口复用 Agent 授权，每次验证当前账号、项目和终端权限，仍只允许具有终端查看及输入权限的超级管理员。切换项目清空终端详情状态。
- `writeFile` 默认可创建或更新已有文件，相同内容直接成功。更新前检查读取及写入权限、保存原文检查点和差异；`overwrite=false` 仍仅允许新建，新建时的竞争写入保护继续生效。只有写入权限时不能读取或覆盖已有文件。

## 消息操作（2026-10-12）

- 鼠标停留或键盘聚焦消息时显示复制和编辑，更多菜单提供删除这轮对话、“撤回到此处 / Undo to this point”和“撤回代码更改”。菜单显示在顶层，并适配手机屏幕。
- 编辑提问会倒序还原该轮及之后可回滚的改动，再使用保留的历史重新发送；编辑回复保存文字记录。复制回复只复制回答正文。
- 删除移除该轮提问及回答，保留文件改动；只在原位置保存不含原文、参数或输出的回滚关联，之后撤回仍能还原该轮的检查点。这些关联不出现在概述页、Saki 消息或模型历史中。
- 撤回使用现有服务端检查点权限校验，按倒序逐项执行。失败时保留完整对话及已成功回滚的状态，重试跳过已完成项。待审批任务先取消，避免删除后再次执行。
- 记录同步至当前账号本机缓存及可用的云端历史；云端保存使用版本校验，其他设备修改后拒绝覆盖。编辑、删除和撤回在生成及其他操作期间禁用。

## 代码撤回补全（2026-10-12）

- 编辑提问的“保存并重新发送”和 Undo 共用回滚流程。点击 AI 回复的 Undo 也包含该回复产生的改动；全部回滚成功后才截断对话并重新发送。新增“撤回代码更改”，还原所选轮次及之后的文件改动，同时保留对话。
- 文件写入、替换、行编辑、补丁、批量编辑、重命名、新目录和软删除均接入检查点。兼容从旧时间线恢复文件操作，即使客户端缺少回滚标记，也会尝试查找服务端已有检查点。
- `runCommand` / `runInShell` 在命令前后记录守护进程本地的工作区文件快照，包含二进制文件、新建和删除路径；无文件变化时移除快照。需要当前账号具有该项目的读取、写入和删除权限，命令失败或取消也会尝试完成快照。Agent 文件变更与回滚按实例串行执行。
- 回滚逐项复验当前账号、检查点归属、明确项目分配、细分权限以及节点和工作目录绑定。文件指纹防止覆盖后续手动修改；终端快照先检查整个变更集，再恢复文件。不会递归删除含有后续手动文件的新目录，也不跟随符号链接读取外部文件。
- 单操作和整任务回滚遇到冲突会停止，保留对话、剩余检查点和已恢复操作状态，修复冲突后可以继续。整任务只统计实际成功恢复的检查点。
- 修复 Agent Git 变更接口在没有项目或目标无效时自动选择首个可见实例的问题。无项目不读取实例变更；Git 撤回及恢复要求明确项目、Agent 权限以及项目读取、写入和删除权限，普通管理员的管理可见性不代替 Agent 项目分配。
- 快照最多包含 20,000 个条目、100 MB 文件内容，超过上限会在命令执行前拒绝；排除 `.git`、`node_modules`、`.venv`、`venv` 和 `.webops-saki-trash`。撤回范围是工作区文件，不包含进程、网络、工作区外文件或 Git 索引。
- 新版本之前没有快照的终端记录、交互终端输入及未完成的快照无法自动恢复。界面会保留对话并明确提示，不能只删除消息后声称代码已撤回。

## 仍存在的限制

应用层授权不是操作系统级租户隔离；项目代码、常驻进程和原有独立终端仍需要部署层的文件、进程和网络隔离。已交付的历史内容不能撤回。普通 Chat 流没有本次 Agent 任务流的逐批权限复验。

## 概述页后台任务复查（2026-10-12）

- 聊天切换按会话保存订阅；页面卸载只移除订阅，返回后按原任务 ID 重连，不重复提交。历史会话右侧显示运行或等待图标，并恢复当前账号选中的会话。
- 提交后立即离开页面会等待任务 ID 返回再断开；提前点击停止会在取得 ID 后取消对应任务，不会误取消该会话上一轮任务。
- 修复历史加载覆盖最新任务状态、失败原因被空内容隐藏、重连失败清空已显示内容，以及重放期间丢失已确认工具状态的问题。
- 停止请求成功后更新停止状态；请求失败时保留运行和接收进度，并显示错误。迟到的停止响应不能覆盖新一轮订阅。
- 清理前 325 项自动化检查及桌面、移动宽度的浏览器检查通过；另验证多聊天后台续跑、审批续跑、快速切页、断线重连、重连失败内容保留、停止失败和账号隔离。
