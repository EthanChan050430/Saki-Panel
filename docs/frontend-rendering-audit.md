# 前端渲染检查（2026-10-11）

## 概述页 Agent 展示更新（2026-10-12）

- 概述页改用无气泡的消息正文与紧凑工具行，移除消息附带的 CPU、内存及在线节点指标。
- 推理复用 Saki 的可折叠组件，显示 `Thinking...` / `Think for XXs`。流式推理按实际片段累计耗时并保存至本地历史；没有耗时数据的旧记录保留 Saki 的估算显示。
- 模型、模式、权限、实例和环境菜单统一挂载到页面顶层，避开玻璃效果的层叠和容器裁剪，随屏幕与滚动调整位置，并支持点击外部及 Escape 关闭。
- 所有工具调用均可打开右侧详情，复用 Saki 的代码差异、文件输出、网页来源、问答和审批组件。窄屏使用可关闭的详情抽屉；详情随最新操作状态更新，审批按钮只显示一份，外部读取仍必须显式点击。
- 293 项回归测试、全项目类型检查及构建通过。完整浏览器检查覆盖 1280、390、320 像素菜单层级，文件读取、代码差异、网页来源、桌面侧栏、手机抽屉、推理展示、账号隔离和审批恢复。

## 已修复

- 概述页未选项目时统一显示“无项目”，并说明可用范围；项目入口按创建者、明确分配和当前 Chat/Agent 模式筛选，展示分配权限提示。浏览器验证无项目文案、未分配项目隐藏、只读项目权限提示及桌面/手机布局通过。

- 消息时间线使用旧的操作快照，导致审批完成后仍显示批准按钮；同一操作 ID 可能重复显示卡片。现在按 ID 使用最新操作状态并去重。
- 只有工具操作的历史时间线可能隐藏最终回复。现在补回最终文本，并保留稳定的渲染 ID；已有多段文本组成完整回复时不会重复追加。
- 待审批操作被误标为失败；流式回复期间仍可点击消息回退。现在分别使用等待状态和禁用回退。
- 命令 `pwd` 被误判为文件链接，而包含空格的文件路径无法点击。现在按工具类型区分命令和文件，支持带空格、中文和 Windows 盘符的显式文件引用。
- Markdown 表格显示为普通文本、有序列表丢失起始编号、C++ 等代码语言名称被截断、长围栏中的短围栏误结束代码块、带括号的 URL 被截断。补充了对应解析与渲染，表格在窄屏内横向滚动。
- 模型返回重复问答选项时出现重复单选项。现在去重后显示。
- 图片解码失败仍显示损坏图片；切换账户可能复用旧账户的生成图片缓存。现在显示失败状态，并按账户令牌与图片 ID 隔离缓存。
- 任务监控的旧请求可能覆盖较新的任务状态。现在丢弃过期结果，并在卸载或切换账户时失效旧请求。
- 等待审批或回答的任务缺少停止按钮、无文件检查点也显示撤销按钮、操作期间其他按钮仍可点击。现在按任务状态与回退能力显示和禁用控件，并补充监控入口的可访问名称。
- 任务监控打开时把网络请求放在状态更新函数中，React 严格模式可能重复请求。现在在点击处理函数中发起请求。
