# Agent 界面与联网检索检查（2026-10-11）

## 界面调整

- 界面精简仅作用于 `.saki-messages` 内部。陪伴画面、底部玻璃材质输入框、顶部按钮、原有展开与手机端陪伴切换方式均保留。
- Agent 消息列表使用纯色明暗背景、简洁消息气泡和正文，减少消息头像与装饰。新的样式全部以 `.saki-messages` 为作用域，Agent 专属样式进一步限定为 `.saki-messages-agent`。
- 连续完成的读取、定位和检查步骤合并为可展开的记录；编辑、失败、待审批、问答及网页来源继续直接显示。
- 消息内的删除、回退和用量明细收进“更多”，复制与重试保留；手机端操作按钮直接可用。消息以外的使用量入口、全屏入口、语音、文本引用、模型及权限选择维持原有界面。
- 提示模型只在有实际进展、阻塞或结论时简短更新。消息以外的任务进度区域保留原有行为。

## 联网链路修复

- 普通聊天模式现在也提供 `searchWeb` 和 `browse`，启用搜索时进入支持工具的对话循环。小模型的工具数量裁剪保留这两个工具。
- 普通聊天和 Agent 的提示均要求：遇到陌生事实、不确定事实、陌生 API、时效性问题或用户明确要求查询时，先搜索，再读取相关的 1–2 个来源，优先官方文档与一手来源，并引用实际返回的网址。
- 增加结束前检查：明确要求联网、询问部分时效事实，或者模型直接表示不确定却未调用联网工具时，要求模型补充核实。普通文本结束和 `respond` 工具结束都覆盖。
- 搜索关闭或用户明确要求不联网时尊重设置；检索失败必须说明无法核实，不得编造来源。网页中的指令视为不可信内容。
- 修复取消后仍继续尝试备用搜索引擎、某条结果没有摘要却错误借用下一条摘要，以及网页标题的数字 HTML 实体未解码的问题。
- 普通聊天不再读项目 Git 摘要，也不会覆盖同用户同工作区正在运行的编码 Agent 检查点。关闭普通聊天连接会取消其请求；编码 Agent 原有的后台运行逻辑保留。

## 搜索来源与跳转

成功的搜索结果在聊天流中显示标题、域名与外链按钮，默认展示前三个来源，展开后显示全部来源及摘要。兼容已有对话保存的工具输出，无需重建历史记录。

来源使用真实 HTTP/HTTPS 链接，点击在新标签页打开对应网址；拒绝带账户密码或非法协议的来源。回复中的 Markdown 链接、裸网址和尖括号网址也可点击，并正确处理末尾标点及 URL 中的括号。

历史联网工具回归使用模拟网络，独立联网检查连接实际搜索服务和网页。浏览器的来源跳转检查验证真实锚点与目标 URL，目标页内容使用固定响应；实际网页可读性由上述独立联网检查验证。模型纠偏回归使用模拟模型回复，没有调用付费模型。未在实体手机或 Safari 验证。当前保留的命令只执行类型检查与构建，不重跑已移除的功能回归。
